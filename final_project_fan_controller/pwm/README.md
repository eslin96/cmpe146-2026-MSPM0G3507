# PWM Fan Control

## Overview

This module is responsible for controlling the speed of a 4-pin 12V PC fan using a 25 kHz PWM signal generated by the MSPM0G3507.

## My Responsibilities

- Configure the MCU timer to generate a 25 kHz PWM signal.
- Implement adjustable PWM duty cycle.
- Develop a reusable fan control driver.
- Use temperature information to determine the target fan speed.
- Use tachometer feedback to adjust the fan speed.
- Test PWM operation before FreeRTOS integration.

## Development Status

PWM driver implementation and testing are in progress.
